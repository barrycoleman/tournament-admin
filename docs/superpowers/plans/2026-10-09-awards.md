# Awards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an organizer define each session's awards (judged or performance), see automatic winners live from teamwork rankings, finals and skills, enter judged winners as an admin or a judge, override automatic winners, finalize the session's awards, and export a ceremony CSV.

**Architecture:**
- **Storage:** an `awards` table (definitions per session), an `award_winners` table (judged entries, overrides, and finalized snapshots), and `sessions.awards_finalized_at`.
- **Sources:** `services/award_sources.py` holds a `SOURCES` registry of pure resolvers (`teamwork_ranking`, `finals`, `skills_overall`, `skills_type`). Each one reads data and returns the winning team ids for one slot. Automatic winners are computed on read and stored only on finalize.
- **Rules:** `services/awards.py` owns definition validation, a slot's divisions, and a slot's status and winners.
- **API:** `routers/awards.py`. Admin writes definitions, overrides and finalize; admin and judge write judged slots; any role reads. Every write broadcasts `awards_changed`.
- **Admin UI:** a session **Awards** tab (`src/awards/`), and a judge navigation (`/judge/awards`, `/judge/rankings`, `/rankings`) for the active session.

**Tech Stack:**
- Server: FastAPI, SQLAlchemy 2.x, Alembic, SQLite, pytest.
- Frontend: React 19, TanStack Query, react-i18next, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-09-awards-design.md`

## Review Focus

1. **Finalizing twice** (a double click, or two admins): the second request gets 409, and no duplicate `finalized` rows are written. Pinned in Task 5: `test_finalize_twice_is_409_and_writes_once`.
2. **A judge choosing a winner after the admin finalized**, with the page still open: the dialog shows the server's "Unfinalize awards to make changes." message, not a generic error. Pinned in Task 7: `WinnerDialog` test "shows the server's message when the session is finalized".
3. **An override listing a team from another division next to a valid team:** 422, and nothing is written (no partial slot). Pinned in Task 4: `test_override_with_one_bad_team_writes_nothing`.
4. **A reorder sent from a stale page** (another admin added an award since): 422, nothing changes, and the UI refetches. Pinned in Task 3: `test_order_must_list_exactly_the_sessions_awards`.
5. **Per-division skills placement with a tie and with teams from other divisions in between:** division renumbering keeps tied teams tied and skips the next placement. Pinned in Task 2: `test_division_skills_renumbers_and_keeps_ties`.

## Decisions where the spec is silent

The executor follows these. They are not open questions.

- **Every event has at least one division** (event creation makes "Division 1"; the last division cannot be deleted). So a `division`-scoped award always has at least one real division slot. The slot path literal `event` addresses the slot with `division_id = NULL` and exists only for `scope = event`.
- **Which finals bracket:** the session's bracket for that division with the highest `id` (a deleted and recreated bracket replaces the old one).
- **`recorded_by`** is the acting role (`"admin"` or `"judge"`), taken from the role dependency.
- **Slot `note` and `warnings` are codes, not English**, so the UI can translate them: `note` is `"unknown_skills_type"`, `"skills_disabled"` or `null`; `warnings` becomes `moved_team_ids: list[int]` (stored winners no longer in the slot's division).
- **PATCH merges** the sent fields onto the stored award, then validates the merged result. Stored winners are deleted only if a rule field's value actually changed.
- **Finalize while already finalized** returns 409, like every other write.
- **Earlier sessions** for team history are ordered with `skills_ranking.session_order_key` (date, undated last, then id).
- **Season-basis winners from other sessions:** the admin's Awards tab hears result events for its own session only. A season-basis winner changed by another session's scores shows on the next refetch (window focus, remount, or any award write).
- **Realtime channels:** the admin's Awards tab listens on `/ws/session/{id}`; the judge's pages listen on `/ws/active-session` (the session channel is admin-only). `SessionRankingsRoute` reads an optional `channelPath` from its outlet context for this.
- **CSV download** uses `apiRequest` with a new `responseType: "text"` option, then saves a Blob, because the endpoint needs the bearer token.
- **Teams still can't be deleted while they have a participation row**, which every winner needs. `delete_team` deletes the team's award winners anyway, as the spec asks.
- **Team order in a slot** is team id order for resolved winners, and insertion order for stored rows (`AwardWinner.id`).

```python
"""Shared setup for the awards tests."""
from __future__ import annotations

from contextlib import contextmanager


def setup_two_divisions(client, per_division: int = 3) -> tuple[int, int, dict[str, int]]:
    """An example-game event with Division 1 (teams A1..An) and Division 2 (B1..Bn)."""
    client.post("/api/event", json={"name": "League"})
    client.post("/api/event/game-plugin", json={"name": "example-game"})
    first = client.get("/api/divisions").json()[0]["id"]
    second = client.post("/api/divisions", json={"name": "Division 2"}).json()["id"]
    teams: dict[str, int] = {}
    for division_id, prefix in ((first, "A"), (second, "B")):
        for n in range(1, per_division + 1):
            number = f"{prefix}{n}"
            response = client.post(
                "/api/teams", json={"number": number, "name": f"Team {number}", "division_id": division_id}
            )
            assert response.status_code == 201, response.text
            teams[number] = response.json()["id"]
    return first, second, teams


def create_session(client, label: str = "Saturday", session_date: str | None = None) -> int:
    body = {"label": label}
    if session_date is not None:
        body["session_date"] = session_date
    return client.post("/api/sessions", json=body).json()["id"]


def enter(client, session_id: int, *team_ids: int) -> None:
    """Gives each team a (checked-in) participation row in the session."""
    for team_id in team_ids:
        response = client.post(
            f"/api/sessions/{session_id}/participants", json={"team_id": team_id, "checked_in": True}
        )
        assert response.status_code == 201, response.text


@contextmanager
def db_session(client):
    db = client.app.state.session_factory()
    try:
        yield db
    finally:
        db.close()
```

```python
from __future__ import annotations

from sqlalchemy import func, select

from award_helpers import create_session, db_session, enter, setup_two_divisions
from tournament_server.models.award import Award, AwardWinner


def _award(db, session_id: int, **overrides) -> Award:
    fields = dict(
        session_id=session_id, name="Judges Award", description=None, position=0, scope="division",
        division_ids=[], kind="judged", source=None, skills_type=None, basis=None, placement=None,
    )
    fields.update(overrides)
    award = Award(**fields)
    db.add(award)
    db.flush()
    return award


def _winner(db, award: Award, division_id, team_id: int) -> None:
    db.add(AwardWinner(award_id=award.id, division_id=division_id, team_id=team_id, origin="judged", recorded_by="admin"))


def _count(db, model, *where) -> int:
    return db.execute(select(func.count()).select_from(model).where(*where)).scalar_one()


def test_deleting_a_session_deletes_its_awards_and_winners(client):
    first, _, teams = setup_two_divisions(client)
    saturday = create_session(client, "Saturday")
    sunday = create_session(client, "Sunday")
    enter(client, saturday, teams["A1"])
    with db_session(client) as db:
        kept = _award(db, sunday)
        gone = _award(db, saturday)
        _winner(db, gone, first, teams["A1"])
        db.commit()
        kept_id = kept.id

    assert client.delete(f"/api/sessions/{saturday}").status_code == 204

    with db_session(client) as db:
        assert _count(db, Award, Award.session_id == saturday) == 0
        assert _count(db, AwardWinner) == 0
        assert db.get(Award, kept_id) is not None


def test_deleting_a_division_drops_it_from_awards_and_deletes_its_winners(client):
    first, second, teams = setup_two_divisions(client)
    saturday = create_session(client)
    enter(client, saturday, teams["A1"], teams["B1"])
    with db_session(client) as db:
        both = _award(db, saturday, division_ids=[first, second])
        only_second = _award(db, saturday, position=1, division_ids=[second])
        _winner(db, both, first, teams["A1"])
        _winner(db, both, second, teams["B1"])
        db.commit()
        both_id, only_second_id = both.id, only_second.id

    assert client.delete(f"/api/divisions/{second}").status_code == 204

    with db_session(client) as db:
        assert db.get(Award, both_id).division_ids == [first]
        # An award left with no divisions covers every division.
        assert db.get(Award, only_second_id).division_ids == []
        remaining = db.execute(select(AwardWinner)).scalars().all()
        assert [(w.division_id, w.team_id) for w in remaining] == [(first, teams["A1"])]


def test_delete_team_award_winners_removes_only_that_teams_rows(client):
    from tournament_server.services.deletion import delete_team_award_winners

    first, _, teams = setup_two_divisions(client)
    saturday = create_session(client)
    with db_session(client) as db:
        award = _award(db, saturday)
        _winner(db, award, first, teams["A1"])
        _winner(db, award, first, teams["A2"])
        db.commit()
        delete_team_award_winners(db, teams["A1"])
        db.commit()
        assert [w.team_id for w in db.execute(select(AwardWinner)).scalars().all()] == [teams["A2"]]
```

```python
    scope: Mapped[str] = mapped_column(String(20))
```

```python
def delete_session_awards(db: Session, session_id: int) -> None:
    """Deletes a session's awards and their winners."""
    awards = db.execute(select(Award).where(Award.session_id == session_id)).scalars().all()
    for award in awards:
        for winner in db.execute(select(AwardWinner).where(AwardWinner.award_id == award.id)).scalars().all():
            db.delete(winner)
    db.flush()
    for award in awards:
        db.delete(award)
    db.flush()


def delete_team_award_winners(db: Session, team_id: int) -> None:
    for winner in db.execute(select(AwardWinner).where(AwardWinner.team_id == team_id)).scalars().all():
        db.delete(winner)
    db.flush()


def remove_division_from_awards(db: Session, division_id: int) -> None:
    """Takes a division out of every award's division list (an award left with
    none then covers every division) and deletes that division's winners."""
    for award in db.execute(select(Award)).scalars().all():
        if division_id in award.division_ids:
            award.division_ids = [d for d in award.division_ids if d != division_id]
    for winner in db.execute(
        select(AwardWinner).where(AwardWinner.division_id == division_id)
    ).scalars().all():
        db.delete(winner)
    db.flush()
```

```python
"""Where performance awards get their winners. Each resolver reads data and
returns the winning team ids for one slot; nothing here writes. Award plugins
will add entries to SOURCES."""
from __future__ import annotations

from dataclasses import dataclass, field
from typing import Callable

from sqlalchemy import select
from sqlalchemy.orm import Session

from tournament_server.deps import get_the_event
from tournament_server.models.award import Award
from tournament_server.models.bracket_alliance import BracketAlliance, BracketAllianceTeam
from tournament_server.models.bracket_matchup import BracketMatchup
from tournament_server.models.finals_bracket import FinalsBracket
from tournament_server.models.finals_result import FinalsResult
from tournament_server.models.ranking import Ranking
from tournament_server.models.session import TournamentSession
from tournament_server.models.team import Team
from tournament_server.plugin_registry.loader import LoadedPlugin
from tournament_server.services import skills as skills_service
from tournament_server.services.skills_ranking import OVERALL, SkillsRankingRow

NOTE_UNKNOWN_SKILLS_TYPE = "unknown_skills_type"
NOTE_SKILLS_DISABLED = "skills_disabled"


@dataclass(frozen=True)
class Resolution:
    team_ids: list[int] = field(default_factory=list)
    # True while the result can still change (a score chase still running).
    provisional: bool = False
    note: str | None = None


def _division_filter(column, division_id: int | None):
    return column.is_(None) if division_id is None else column == division_id


def _teamwork_ranking(db: Session, plugin: LoadedPlugin | None, award: Award, division_id: int | None) -> Resolution:
    session_filter = (
        Ranking.session_id == award.session_id if award.basis == "session" else Ranking.session_id.is_(None)
    )
    team_ids = db.execute(
        select(Ranking.team_id)
        .where(session_filter, _division_filter(Ranking.division_id, division_id), Ranking.rank == award.placement)
        .order_by(Ranking.team_id)
    ).scalars().all()
    return Resolution(list(team_ids))


def _alliance_team_ids(db: Session, bracket_alliance_id: int) -> list[int]:
    return list(
        db.execute(
            select(BracketAllianceTeam.team_id)
            .where(BracketAllianceTeam.bracket_alliance_id == bracket_alliance_id)
            .order_by(BracketAllianceTeam.team_id)
        ).scalars().all()
    )


def single_elimination_placements(db: Session, bracket: FinalsBracket) -> dict[int, int]:
    """Placement -> bracket alliance id, for every placement already decided.
    1st and 2nd come from the final. Below that, alliances are grouped by the
    round they lost in (later rounds first) and ordered by seed inside a
    group; a group counts only once every matchup in its round is decided."""
    matchups = db.execute(select(BracketMatchup).where(BracketMatchup.bracket_id == bracket.id)).scalars().all()
    if not matchups:
        return {}
    seeds = {
        a.id: a.seed
        for a in db.execute(select(BracketAlliance).where(BracketAlliance.bracket_id == bracket.id)).scalars().all()
    }
    total_rounds = max(m.round_number for m in matchups)
    placements: dict[int, int] = {}
    next_place = 1
    for round_number in range(total_rounds, 0, -1):
        # A round-1 matchup with an empty side is a bye: it has no loser.
        contested = [
            m for m in matchups
            if m.round_number == round_number
            and (round_number > 1 or (m.alliance_a_id is not None and m.alliance_b_id is not None))
        ]
        decided = all(m.winner_alliance_id is not None for m in contested)
        if round_number == total_rounds:
            if decided and contested:
                final = contested[0]
                placements[1] = final.winner_alliance_id
                placements[2] = _loser(final)
            next_place = 3
            continue
        if decided:
            losers = sorted((_loser(m) for m in contested), key=lambda alliance_id: seeds[alliance_id])
            for offset, alliance_id in enumerate(losers):
                placements[next_place + offset] = alliance_id
        next_place += len(contested)
    return placements


def _loser(matchup: BracketMatchup) -> int:
    return matchup.alliance_b_id if matchup.winner_alliance_id == matchup.alliance_a_id else matchup.alliance_a_id


def _finals(db: Session, plugin: LoadedPlugin | None, award: Award, division_id: int | None) -> Resolution:
    bracket = db.execute(
        select(FinalsBracket)
        .where(FinalsBracket.session_id == award.session_id, _division_filter(FinalsBracket.division_id, division_id))
        .order_by(FinalsBracket.id.desc())
    ).scalars().first()
    if bracket is None:
        return Resolution()
    if bracket.format == "score_chase":
        result = db.execute(
            select(FinalsResult).where(
                FinalsResult.finals_bracket_id == bracket.id, FinalsResult.rank == award.placement
            )
        ).scalars().first()
        if result is None:
            return Resolution()
        return Resolution(
            _alliance_team_ids(db, result.bracket_alliance_id), provisional=bracket.status != "complete"
        )
    alliance_id = single_elimination_placements(db, bracket).get(award.placement)
    if alliance_id is None:
        return Resolution()
    return Resolution(_alliance_team_ids(db, alliance_id))


def _renumbered(rows: list[SkillsRankingRow]) -> list[tuple[int, int]]:
    """(rank, team_id) after filtering: tied rows keep sharing a rank, and the
    next rank skips, as rank_skills numbers them."""
    out: list[tuple[int, int]] = []
    previous_rank = None
    rank = 0
    for index, row in enumerate(rows, start=1):
        if row.rank != previous_rank:
            rank, previous_rank = index, row.rank
        out.append((rank, row.team_id))
    return out


def _skills(db: Session, plugin: LoadedPlugin | None, award: Award, division_id: int | None) -> Resolution:
    event = get_the_event(db)
    if event is None or not skills_service.is_enabled(db, event.id):
        return Resolution(note=NOTE_SKILLS_DISABLED)
    type_keys = [t["key"] for t in skills_service.plugin_types(plugin)]
    tab = OVERALL if award.source == "skills_overall" else award.skills_type
    if tab != OVERALL and tab not in type_keys:
        return Resolution(note=NOTE_UNKNOWN_SKILLS_TYPE)
    if award.basis == "session":
        sessions = [db.get(TournamentSession, award.session_id)]
    else:
        sessions = list(
            db.execute(select(TournamentSession).where(TournamentSession.event_id == event.id)).scalars().all()
        )
    rows = skills_service.compute_rankings(db, type_keys, tab, sessions)
    if division_id is not None:
        in_division = set(db.execute(select(Team.id).where(Team.division_id == division_id)).scalars().all())
        rows = [row for row in rows if row.team_id in in_division]
    return Resolution(sorted(team_id for rank, team_id in _renumbered(rows) if rank == award.placement))


SOURCES: dict[str, Callable[[Session, LoadedPlugin | None, Award, int | None], Resolution]] = {
    "teamwork_ranking": _teamwork_ranking,
    "finals": _finals,
    "skills_overall": _skills,
    "skills_type": _skills,
}


def resolve(db: Session, plugin: LoadedPlugin | None, award: Award, division_id: int | None) -> Resolution:
    return SOURCES[award.source](db, plugin, award, division_id)
```

```python
"""Award rules against the database: definition validation, a slot's
divisions, and a slot's status and winners. Sources live in award_sources.py."""
from __future__ import annotations

from dataclasses import dataclass, field

from sqlalchemy import select
from sqlalchemy.orm import Session

from tournament_server.models.award import Award, AwardWinner
from tournament_server.models.division import Division
from tournament_server.models.team import Team
from tournament_server.plugin_registry.loader import LoadedPlugin
from tournament_server.services.award_sources import SOURCES, resolve

JUDGED = "judged"
PERFORMANCE = "performance"
EVENT = "event"
DIVISION = "division"
ORIGIN_JUDGED = "judged"
ORIGIN_OVERRIDE = "override"
ORIGIN_FINALIZED = "finalized"
BASES = ("session", "season")
# Sources whose results never cross divisions.
DIVISION_ONLY_SOURCES = ("teamwork_ranking", "finals")
RULE_FIELDS = ("kind", "scope", "division_ids", "source", "skills_type", "basis", "placement")
LOCKED_DETAIL = "Unfinalize awards to make changes."
NAME_MAX = 200
DESCRIPTION_MAX = 2000


def definition_error(d: dict, event_division_ids: set[int]) -> str | None:
    """Why a (normalized) definition is invalid, or None."""
    if not d["name"]:
        return "An award needs a name."
    if len(d["name"]) > NAME_MAX:
        return f"An award name can be at most {NAME_MAX} characters."
    if d["description"] is not None and len(d["description"]) > DESCRIPTION_MAX:
        return f"A description can be at most {DESCRIPTION_MAX} characters."
    if d["kind"] not in (JUDGED, PERFORMANCE):
        return "kind must be 'judged' or 'performance'."
    if d["scope"] not in (EVENT, DIVISION):
        return "scope must be 'event' or 'division'."
    if d["scope"] == EVENT and d["division_ids"]:
        return "An event-wide award has no divisions."
    unknown = [i for i in d["division_ids"] if i not in event_division_ids]
    if unknown:
        return f"Unknown division ids: {unknown}."
    if len(set(d["division_ids"])) != len(d["division_ids"]):
        return "A division is listed twice."
    if d["kind"] == JUDGED:
        if any(d[k] is not None for k in ("source", "skills_type", "basis", "placement")):
            return "A judged award has no source, skills type, basis or placement."
        return None
    if d["source"] not in SOURCES:
        return f"source must be one of {sorted(SOURCES)}."
    if d["basis"] not in BASES:
        return "basis must be 'session' or 'season'."
    if d["placement"] is None or d["placement"] < 1:
        return "placement must be 1 or more."
    if (d["source"] == "skills_type") != (d["skills_type"] is not None):
        return "skills_type is required for, and only allowed with, the skills_type source."
    if d["source"] in DIVISION_ONLY_SOURCES and d["scope"] != DIVISION:
        return "Teamwork ranking and finals awards are per division."
    if d["source"] == "finals" and d["basis"] != "session":
        return "Finals awards use the session's finals."
    return None


def normalized(d: dict) -> dict:
    """Trims the name and description; an empty description becomes None."""
    out = dict(d)
    out["name"] = (out.get("name") or "").strip()
    description = (out.get("description") or "").strip()
    out["description"] = description or None
    out["division_ids"] = list(out.get("division_ids") or [])
    return out


def event_division_ids(db: Session) -> list[int]:
    return list(db.execute(select(Division.id).order_by(Division.id)).scalars().all())


def slot_division_ids(db: Session, award: Award) -> list[int | None]:
    if award.scope == EVENT:
        return [None]
    all_ids = event_division_ids(db)
    if not award.division_ids:
        return all_ids
    return [i for i in all_ids if i in award.division_ids]


def session_awards(db: Session, session_id: int) -> list[Award]:
    return list(
        db.execute(
            select(Award).where(Award.session_id == session_id).order_by(Award.position, Award.id)
        ).scalars().all()
    )


def stored_winners(db: Session, award_id: int, division_id: int | None) -> list[AwardWinner]:
    division_filter = (
        AwardWinner.division_id.is_(None) if division_id is None else AwardWinner.division_id == division_id
    )
    return list(
        db.execute(
            select(AwardWinner).where(AwardWinner.award_id == award_id, division_filter).order_by(AwardWinner.id)
        ).scalars().all()
    )


@dataclass
class SlotState:
    division_id: int | None
    status: str
    team_ids: list[int] = field(default_factory=list)
    override_reason: str | None = None
    note: str | None = None
    moved_team_ids: list[int] = field(default_factory=list)


def _moved(db: Session, division_id: int | None, team_ids: list[int]) -> list[int]:
    if division_id is None:
        return []
    return [t for t in team_ids if (team := db.get(Team, t)) is not None and team.division_id != division_id]


def slot_state(db: Session, plugin: LoadedPlugin | None, award: Award, division_id: int | None) -> SlotState:
    rows = stored_winners(db, award.id, division_id)
    if rows:
        team_ids = [row.team_id for row in rows]
        origin = rows[0].origin
        status = {ORIGIN_JUDGED: "judged", ORIGIN_OVERRIDE: "overridden", ORIGIN_FINALIZED: "finalized"}[origin]
        return SlotState(
            division_id, status, team_ids,
            override_reason=rows[0].override_reason if origin == ORIGIN_OVERRIDE else None,
            moved_team_ids=_moved(db, division_id, team_ids),
        )
    if award.kind == JUDGED:
        return SlotState(division_id, "judged_pending")
    resolution = resolve(db, plugin, award, division_id)
    if not resolution.team_ids:
        return SlotState(division_id, "no_result", note=resolution.note)
    status = "provisional" if resolution.provisional else "resolved"
    return SlotState(division_id, status, list(resolution.team_ids), note=resolution.note)
```

```python
"""Awards: definitions, winners, finalize, team history and the CSV export."""
from __future__ import annotations

from fastapi import APIRouter, Depends, HTTPException, Request, Response
from sqlalchemy import select
from sqlalchemy.orm import Session

from tournament_server.auth import require_admin, require_any_role
from tournament_server.deps import get_db, get_event_or_404, get_optional_game_plugin
from tournament_server.models.award import Award, AwardWinner
from tournament_server.models.division import Division
from tournament_server.models.session import TournamentSession
from tournament_server.models.team import Team
from tournament_server.plugin_registry.loader import LoadedPlugin
from tournament_server.realtime import broadcast_for_session
from tournament_server.schemas.award import (
    AwardBody,
    AwardCopyBody,
    AwardOrderBody,
    AwardPatch,
    AwardRead,
    AwardSlotRead,
    SessionAwardsRead,
    WinnerTeamRead,
)
from tournament_server.services import awards as rules

router = APIRouter(tags=["awards"])

DEFINITION_FIELDS = ("name", "description", *rules.RULE_FIELDS)


def _session_or_404(db: Session, session_id: int) -> TournamentSession:
    session_obj = db.get(TournamentSession, session_id)
    if session_obj is None:
        raise HTTPException(status_code=404, detail="Session not found")
    return session_obj


def _award_or_404(db: Session, award_id: int) -> Award:
    award = db.get(Award, award_id)
    if award is None:
        raise HTTPException(status_code=404, detail="Award not found")
    return award


def _ensure_open(session_obj: TournamentSession) -> None:
    if session_obj.awards_finalized_at is not None:
        raise HTTPException(status_code=409, detail=rules.LOCKED_DETAIL)


def _plugin(request: Request, db: Session) -> LoadedPlugin | None:
    return get_optional_game_plugin(request, get_event_or_404(db))


def _changed(request: Request, db: Session, session_id: int) -> None:
    broadcast_for_session(request.app, db, session_id, "awards_changed", {"session_id": session_id})


def _team_read(db: Session, team_id: int) -> WinnerTeamRead:
    team = db.get(Team, team_id)
    return WinnerTeamRead(team_id=team.id, number=team.number, name=team.name, organization=team.organization)


def _award_read(db: Session, plugin: LoadedPlugin | None, award: Award) -> AwardRead:
    slots = []
    for division_id in rules.slot_division_ids(db, award):
        state = rules.slot_state(db, plugin, award, division_id)
        division = db.get(Division, division_id) if division_id is not None else None
        slots.append(
            AwardSlotRead(
                division_id=division_id,
                division_name=division.name if division is not None else None,
                status=state.status,
                winners=[_team_read(db, t) for t in state.team_ids],
                override_reason=state.override_reason,
                note=state.note,
                moved_team_ids=state.moved_team_ids,
            )
        )
    return AwardRead(
        id=award.id, session_id=award.session_id, position=award.position,
        **{name: getattr(award, name) for name in DEFINITION_FIELDS},
        slots=slots,
    )


def _session_read(db: Session, plugin: LoadedPlugin | None, session_obj: TournamentSession) -> SessionAwardsRead:
    return SessionAwardsRead(
        awards_finalized_at=session_obj.awards_finalized_at,
        awards=[_award_read(db, plugin, a) for a in rules.session_awards(db, session_obj.id)],
    )


def _validated(db: Session, definition: dict) -> dict:
    definition = rules.normalized(definition)
    error = rules.definition_error(definition, set(rules.event_division_ids(db)))
    if error is not None:
        raise HTTPException(status_code=422, detail=error)
    return definition


def _renumber(db: Session, session_id: int) -> None:
    for position, award in enumerate(rules.session_awards(db, session_id)):
        award.position = position


@router.get("/api/sessions/{session_id}/awards", response_model=SessionAwardsRead)
def list_awards(
    session_id: int, request: Request, db: Session = Depends(get_db), _role: str = Depends(require_any_role)
) -> SessionAwardsRead:
    return _session_read(db, _plugin(request, db), _session_or_404(db, session_id))


@router.post("/api/sessions/{session_id}/awards", response_model=AwardRead, status_code=201)
def create_award(
    session_id: int,
    payload: AwardBody,
    request: Request,
    db: Session = Depends(get_db),
```

```python
    if award.kind == rules.JUDGED:

def team_history(
    session_id: int, request: Request, db: Session = Depends(get_db), _role: str = Depends(require_any_role)
) -> list[TeamAwardHistoryRead]:
    """Each team's awards in this session (stored and live) and in earlier
    sessions of the season (stored only)."""
    current = _session_or_404(db, session_id)
    current_key = session_order_key(current.session_date, current.id)
    sessions = [
        s for s in db.execute(
            select(TournamentSession).where(TournamentSession.event_id == current.event_id)
        ).scalars().all()
        if session_order_key(s.session_date, s.id) <= current_key
    ]
    sessions.sort(key=lambda s: session_order_key(s.session_date, s.id))
    plugin = _plugin(request, db)
    by_team: dict[int, list[TeamAwardEntryRead]] = {}
    for session_obj in sessions:
        for award in rules.session_awards(db, session_obj.id):
            for division_id in rules.slot_division_ids(db, award):
                if session_obj.id == session_id:
                    team_ids = rules.slot_state(db, plugin, award, division_id).team_ids
                else:
                    team_ids = [row.team_id for row in rules.stored_winners(db, award.id, division_id)]
                for team_id in team_ids:
                    by_team.setdefault(team_id, []).append(
                        TeamAwardEntryRead(
                            award_id=award.id, award_name=award.name, kind=award.kind,
                            session_id=session_obj.id, session_label=session_obj.label,
                        )
                    )
    return [TeamAwardHistoryRead(team_id=team_id, awards=by_team[team_id]) for team_id in sorted(by_team)]
```

```python
WARNING_STATUSES = ("judged_pending", "no_result", "provisional")


@router.post("/api/sessions/{session_id}/awards/finalize", response_model=FinalizeRead)
def finalize_awards(
    session_id: int,
    payload: FinalizeBody,
    request: Request,
    db: Session = Depends(get_db),
    _role: str = Depends(require_admin),
) -> FinalizeRead:
    session_obj = _session_or_404(db, session_id)
    _ensure_open(session_obj)
    plugin = _plugin(request, db)
    warnings: list[FinalizeWarningRead] = []
    snapshot: list[tuple[Award, int | None, list[int]]] = []
    for award in rules.session_awards(db, session_id):
        for division_id in rules.slot_division_ids(db, award):
            state = rules.slot_state(db, plugin, award, division_id)
            if state.status in WARNING_STATUSES:
                division = db.get(Division, division_id) if division_id is not None else None
                warnings.append(
                    FinalizeWarningRead(
                        award_id=award.id, award_name=award.name, division_id=division_id,
                        division_name=division.name if division is not None else None, status=state.status,
                    )
                )
            if state.status in ("resolved", "provisional"):
                snapshot.append((award, division_id, state.team_ids))
    if not payload.confirm:
        return FinalizeRead(awards_finalized_at=None, warnings=warnings)
    for award, division_id, team_ids in snapshot:
        for team_id in team_ids:
            db.add(
                AwardWinner(
                    award_id=award.id, division_id=division_id, team_id=team_id,
                    origin=rules.ORIGIN_FINALIZED, recorded_by="admin",
                )
            )
    session_obj.awards_finalized_at = utc_now()
    db.commit()
    _changed(request, db, session_id)
    return FinalizeRead(awards_finalized_at=session_obj.awards_finalized_at, warnings=warnings)


@router.post("/api/sessions/{session_id}/awards/unfinalize", response_model=SessionAwardsRead)
def unfinalize_awards(
    session_id: int, request: Request, db: Session = Depends(get_db), _role: str = Depends(require_admin)
) -> SessionAwardsRead:
    session_obj = _session_or_404(db, session_id)
    if session_obj.awards_finalized_at is None:
        raise HTTPException(status_code=409, detail="Awards are not finalized.")
    award_ids = [a.id for a in rules.session_awards(db, session_id)]
    for row in db.execute(
        select(AwardWinner).where(
            AwardWinner.award_id.in_(award_ids), AwardWinner.origin == rules.ORIGIN_FINALIZED
        )
    ).scalars().all():
        db.delete(row)
    session_obj.awards_finalized_at = None
    db.commit()
    _changed(request, db, session_id)
    return _session_read(db, _plugin(request, db), session_obj)


CSV_COLUMNS = ["award", "description", "division", "placement", "team_number", "team_name", "organization", "status"]


@router.get("/api/sessions/{session_id}/awards.csv")
def awards_csv(
    session_id: int, request: Request, db: Session = Depends(get_db), _role: str = Depends(require_any_role)
) -> Response:
    session_read = _session_read(db, _plugin(request, db), _session_or_404(db, session_id))
    out = io.StringIO()
    writer = csv.writer(out, lineterminator="\n")
    writer.writerow(CSV_COLUMNS)
    for award in session_read.awards:
        placement = "" if award.placement is None else str(award.placement)
        for slot in award.slots:
            base = [award.name, award.description or "", slot.division_name or "", placement]
            if not slot.winners:
                writer.writerow([*base, "", "", "", slot.status])
            for team in slot.winners:
                writer.writerow([*base, team.number, team.name, team.organization or "", slot.status])
    return Response(
        content=out.getvalue(),
        media_type="text/csv",
        headers={"Content-Disposition": f'attachment; filename="awards-{session_id}.csv"'},
    )
```

> Awards are defined per session (`awards`, ordered by `position`). An award is `judged` (people choose the winner) or `performance` (its winners come from a source at a placement). `scope` is `event` (one slot) or `division` (one slot per division in `division_ids`; `[]` means every division). Sources live in `services/award_sources.py`'s `SOURCES` registry: `teamwork_ranking` (stored `Ranking` rows; `basis` session or season), `finals` (the session's newest bracket for the division; score chase by `FinalsResult.rank`, provisional until complete; single elimination by the round an alliance lost in, then seed), `skills_overall` and `skills_type` (`services/skills.compute_rankings`, filtered to the division and renumbered). Teamwork ranking and finals require division scope; finals require session basis. Automatic winners are computed on read and stored only when an admin finalizes the session (`sessions.awards_finalized_at`), as `award_winners` rows with origin `finalized`; judged entries and admin overrides are stored as `judged` and `override` rows. While a session's awards are finalized, every award write for it returns 409 until `POST .../awards/unfinalize`, which deletes only the `finalized` rows. Admins do everything; judges may set and clear judged slots only (`PUT/DELETE /api/awards/{id}/slots/{division id|event}`); every role can read the awards, the team history, and `GET /api/sessions/{id}/awards.csv`. Every write broadcasts `awards_changed {session_id}` with `broadcast_for_session`.

```ts
import type { TFunction } from "i18next";
import type { AwardBasis, AwardDefinition, AwardKind, AwardScope, AwardSource } from "../types";

/** The award form's editable state; placement stays a string while typed. */
export interface AwardDraft {
  name: string;
  description: string;
  kind: AwardKind;
  scope: AwardScope;
  allDivisions: boolean;
  divisionIds: number[];
  source: AwardSource;
  skillsType: string;
  basis: AwardBasis;
  placement: string;
}

const ALL_SOURCES: AwardSource[] = ["teamwork_ranking", "finals", "skills_overall", "skills_type"];
const RULE_FIELDS = ["kind", "scope", "division_ids", "source", "skills_type", "basis", "placement"] as const;

export function emptyDraft(): AwardDraft {
  return {
    name: "",
    description: "",
    kind: "judged",
    scope: "division",
    allDivisions: true,
    divisionIds: [],
    source: "teamwork_ranking",
    skillsType: "",
    basis: "session",
    placement: "1",
  };
}

/** Teamwork rankings and finals never compare teams across divisions. */
export function allowedSources(scope: AwardScope): AwardSource[] {
  return scope === "event" ? ["skills_overall", "skills_type"] : ALL_SOURCES;
}

export function draftFromAward(award: AwardDefinition): AwardDraft {
  const base = emptyDraft();
  return {
    name: award.name,
    description: award.description ?? "",
    kind: award.kind,
    scope: award.scope,
    allDivisions: award.division_ids.length === 0,
    divisionIds: [...award.division_ids],
    source: award.source ?? base.source,
    skillsType: award.skills_type ?? "",
    basis: award.basis ?? base.basis,
    placement: award.placement === null ? base.placement : String(award.placement),
  };
}

export function draftToBody(draft: AwardDraft): AwardDefinition {
  const description = draft.description.trim();
  const divisionIds =
    draft.scope === "division" && !draft.allDivisions ? [...draft.divisionIds].sort((a, b) => a - b) : [];
  const common = {
    name: draft.name.trim(),
    description: description === "" ? null : description,
    kind: draft.kind,
    scope: draft.scope,
    division_ids: divisionIds,
  };
  if (draft.kind === "judged") {
    return { ...common, source: null, skills_type: null, basis: null, placement: null };
  }
  const source = allowedSources(draft.scope).includes(draft.source) ? draft.source : "skills_overall";
  return {
    ...common,
    source,
    skills_type: source === "skills_type" ? draft.skillsType : null,
    basis: source === "finals" ? "session" : draft.basis,
    placement: Number(draft.placement),
  };
}

/** The first problem with the draft, as an i18n key, or null. */
export function draftError(draft: AwardDraft): string | null {
  if (draft.name.trim() === "") return "awards.form.errors.nameRequired";
  if (draft.scope === "division" && !draft.allDivisions && draft.divisionIds.length === 0) {
    return "awards.form.errors.divisions";
  }
  if (draft.kind === "performance") {
    if (!/^[1-9][0-9]*$/.test(draft.placement.trim())) return "awards.form.errors.placement";
    if (draft.source === "skills_type" && draft.skillsType === "") return "awards.form.errors.skillsType";
  }
  return null;
}

/** Whether saving `body` would clear the award's stored winners. */
export function ruleChanged(award: AwardDefinition, body: AwardDefinition): boolean {
  return RULE_FIELDS.some((field) => JSON.stringify(award[field]) !== JSON.stringify(body[field]));
}

const SOURCE_KEYS: Record<AwardSource, string> = {
  teamwork_ranking: "awards.source.teamworkRanking",
  finals: "awards.source.finals",
  skills_overall: "awards.source.skillsOverall",
  skills_type: "awards.source.skillsType",
};

export function sourceLabel(t: TFunction, award: AwardDefinition, typeLabels: Record<string, string>): string {
  if (award.source === "skills_type") {
    const type = award.skills_type ?? "";
    return t("awards.source.skillsTypeNamed", { type: typeLabels[type] ?? type });
  }
  return award.source ? t(SOURCE_KEYS[award.source]) : "";
}

/** One line describing how the winner is chosen. */
export function ruleSummary(t: TFunction, award: AwardDefinition, typeLabels: Record<string, string>): string {
  const scope = t(`awards.scope.${award.scope}`);
  if (award.kind === "judged") return t("awards.summary.judged", { scope });
  return t("awards.summary.performance", {
    source: sourceLabel(t, award, typeLabels),
    placement: award.placement,
    basis: t(`awards.basis.${award.basis}`),
    scope,
  });
}
```

```ts
  link.click();
```

```tsx
import { useId, useState } from "react";

import { useTranslation } from "react-i18next";

import { Modal } from "../components/Modal";
import { apiErrorMessage } from "../apiErrorMessage";
import type { AwardRead, AwardSource, Division } from "../types";
import {
  allowedSources,
  draftError,
  draftFromAward,
  draftToBody,
  emptyDraft,
  ruleChanged,
  type AwardDraft,

import { awardsKey, teamHistoryKey } from "./useAwards";

const SOURCE_LABEL_KEYS: Record<AwardSource, string> = {
  teamwork_ranking: "awards.source.teamworkRanking",
  finals: "awards.source.finals",
  skills_overall: "awards.source.skillsOverall",
  skills_type: "awards.source.skillsType",
};

/** Add (award = null) or edit an award. */
export function AwardFormDialog({
  sessionId,
  award,
  divisions,
  skillsTypes,
  onClose,
}: {
  sessionId: number;
  award: AwardRead | null;
  divisions: Division[];
  skillsTypes: { key: string; label: string }[];
  onClose: () => void;
}) {
  const { t } = useTranslation();
  const headingId = useId();
  const queryClient = useQueryClient();
  const [draft, setDraft] = useState<AwardDraft>(award ? draftFromAward(award) : emptyDraft());
  const [submitted, setSubmitted] = useState(false);
  const set = (patch: Partial<AwardDraft>) => setDraft((current) => ({ ...current, ...patch }));

  const save = useMutation({
    mutationFn: () => {
      const body = draftToBody(draft);
      return award
        ? apiRequest(`/api/awards/${award.id}`, { method: "PATCH", body })
        : apiRequest(`/api/sessions/${sessionId}/awards`, { method: "POST", body });
    },
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: awardsKey(sessionId) });
      queryClient.invalidateQueries({ queryKey: teamHistoryKey(sessionId) });
      onClose();
    },
  });

  const error = draftError(draft);
  const hasWinners = award?.slots.some((slot) => slot.status === "judged" || slot.status === "overridden");
  const showRuleWarning = award !== null && hasWinners && ruleChanged(award, draftToBody(draft));
  const sources = allowedSources(draft.scope);

  return (
    <Modal labelledBy={headingId} onCancel={() => !save.isPending && onClose()}>
      <form
        className="panel--form"
        onSubmit={(event) => {
          event.preventDefault();
          setSubmitted(true);
          if (error === null && !save.isPending) save.mutate();
        }}
      >
        <h2 id={headingId}>{t(award ? "awards.form.editHeading" : "awards.form.addHeading")}</h2>
        <label className="field">
          <span className="field__label">{t("awards.form.nameLabel")}</span>
          <input className="input" value={draft.name} maxLength={200} data-autofocus onChange={(e) => set({ name: e.target.value })} />
        </label>
        <label className="field">
          <span className="field__label">{t("awards.form.descriptionLabel")}</span>
          <textarea
            className="input"
            value={draft.description}
            maxLength={2000}
            onChange={(e) => set({ description: e.target.value })}
          />
        </label>
        <fieldset className="field">
          <legend className="field__label">{t("awards.form.kindLabel")}</legend>
          {(["judged", "performance"] as const).map((kind) => (
            <label key={kind}>
              <input type="radio" name="kind" checked={draft.kind === kind} onChange={() => set({ kind })} />{" "}
              {t(kind === "judged" ? "awards.form.kindJudged" : "awards.form.kindPerformance")}
            </label>
          ))}
        </fieldset>
        <fieldset className="field">
          <legend className="field__label">{t("awards.form.scopeLabel")}</legend>
          {(["event", "division"] as const).map((scope) => (
            <label key={scope}>
              <input
                type="radio"
                name="scope"
                checked={draft.scope === scope}
                onChange={() =>
                  set({ scope, source: allowedSources(scope).includes(draft.source) ? draft.source : "skills_overall" })
                }
              />{" "}
              {t(scope === "event" ? "awards.form.scopeEvent" : "awards.form.scopeDivision")}
            </label>
          ))}
          {draft.scope === "division" && divisions.length > 1 && (
            <div>
              <label>
                <input
                  type="checkbox"
                  checked={draft.allDivisions}
                  onChange={(e) => set({ allDivisions: e.target.checked })}
                />{" "}
                {t("awards.form.allDivisions")}
              </label>
              {!draft.allDivisions &&
                divisions.map((division) => (
                  <label key={division.id}>
                    <input
                      type="checkbox"
                      checked={draft.divisionIds.includes(division.id)}
                      onChange={(e) =>
                        set({
                          divisionIds: e.target.checked
                            ? [...draft.divisionIds, division.id]
                            : draft.divisionIds.filter((id) => id !== division.id),
                        })
                      }
                    />{" "}
                    {division.name}
                  </label>
                ))}
            </div>
          )}
        </fieldset>
        {draft.kind === "performance" && (
          <>
            <label className="field">
              <span className="field__label">{t("awards.form.sourceLabel")}</span>
              <select
                className="input"
                value={draft.source}
                onChange={(e) => set({ source: e.target.value as AwardSource })}
              >
                {sources.map((source) => (
                  <option key={source} value={source}>
                    {t(SOURCE_LABEL_KEYS[source])}
                  </option>
                ))}
              </select>
            </label>
            {draft.source === "skills_type" && (
              <label className="field">
                <span className="field__label">{t("awards.form.skillsTypeLabel")}</span>
                <select className="input" value={draft.skillsType} onChange={(e) => set({ skillsType: e.target.value })}>
                  <option value="" />
                  {skillsTypes.map((type) => (
                    <option key={type.key} value={type.key}>
                      {type.label}
                    </option>
                  ))}
                </select>
              </label>
            )}
            {draft.source !== "finals" && (
              <label className="field">
                <span className="field__label">{t("awards.form.basisLabel")}</span>
                <select
                  className="input"
                  value={draft.basis}
                  onChange={(e) => set({ basis: e.target.value as AwardDraft["basis"] })}
                >
                  <option value="session">{t("awards.form.basisSession")}</option>
                  <option value="season">{t("awards.form.basisSeason")}</option>
                </select>
              </label>
            )}
            <label className="field">
              <span className="field__label">{t("awards.form.placementLabel")}</span>
              <input
                className="input"
                inputMode="numeric"
                value={draft.placement}
                onChange={(e) => set({ placement: e.target.value })}
              />
            </label>
          </>
        )}
        {showRuleWarning && (
          <p className="alert alert-warning" role="status">
            {t("awards.form.ruleChangeWarning")}
          </p>
        )}
        {submitted && error && (
          <p className="alert alert-danger" role="alert">
            {t(error)}
          </p>
        )}
        {save.isError && (
          <p className="alert alert-danger" role="alert">
            {apiErrorMessage(save.error, t("errors.generic"))}
          </p>
        )}
        <div className="dialog__actions">
          <button type="submit" className="btn btn-primary" disabled={save.isPending}>
            {t("awards.form.save")}
          </button>
          <button type="button" className="btn" onClick={onClose} disabled={save.isPending}>
            {t("awards.cancel")}
          </button>
        </div>
      </form>
    </Modal>
  );
}
```

```ts
import type { TeamAwardEntry, TeamAwardHistory } from "../types";

/** The team's awards other than the one being chosen. */
export function otherAwards(history: TeamAwardHistory[], teamId: number, awardId: number): TeamAwardEntry[] {
  return (history.find((h) => h.team_id === teamId)?.awards ?? []).filter((a) => a.award_id !== awardId);
}

/** "session" if the team already won a judged award in this session, else
 * "season" if it won one earlier in the season, else null. */
export function judgedWarning(
  history: TeamAwardHistory[],
  teamId: number,
  awardId: number,
  sessionId: number
): "session" | "season" | null {
  const judged = otherAwards(history, teamId, awardId).filter((a) => a.kind === "judged");
  if (judged.some((a) => a.session_id === sessionId)) return "session";
  if (judged.length > 0) return "season";
  return null;
}
```

```tsx
import { useId, useMemo, useState } from "react";
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { useTranslation } from "react-i18next";
import { apiRequest } from "@tournament-admin/shared";
import { Modal } from "../components/Modal";
import { apiErrorMessage } from "../apiErrorMessage";
import { matchTeams } from "../skills/recordForm";
import type { AwardRead, AwardSlotRead, TeamSummary } from "../types";
import { judgedWarning, otherAwards } from "./teamHistory";
import { awardsKey, slotKey, teamHistoryKey, useTeamHistory } from "./useAwards";

interface Participant {
  team_id: number;
  checked_in: boolean;
}

/** Choose a judged winner (one team) or override a performance slot (teams and a reason). */
export function WinnerDialog({
  sessionId,
  award,
  slot,
  mode,
  onClose,
}: {
  sessionId: number;
  award: AwardRead;
  slot: AwardSlotRead;
  mode: "judged" | "override";
  onClose: () => void;
}) {
  const { t } = useTranslation();
  const headingId = useId();
  const searchId = useId();
  const queryClient = useQueryClient();
  const teams = useQuery({ queryKey: ["teams"], queryFn: () => apiRequest<TeamSummary[]>("/api/teams") });
  const participants = useQuery({
    queryKey: ["participants", sessionId],
    queryFn: () => apiRequest<Participant[]>(`/api/sessions/${sessionId}/participants`),
  });
  const history = useTeamHistory(sessionId);
  const [search, setSearch] = useState("");
  const [chosen, setChosen] = useState<number[]>(slot.winners.map((w) => w.team_id));
  const [reason, setReason] = useState(slot.override_reason ?? "");
  const [problem, setProblem] = useState<string | null>(null);

  const eligible = useMemo(() => {
    const entered = new Set((participants.data ?? []).map((p) => p.team_id));
    return (teams.data ?? []).filter(
      (team) => entered.has(team.id) && (slot.division_id === null || team.division_id === slot.division_id)
    );
  }, [teams.data, participants.data, slot.division_id]);
  const shown = matchTeams(eligible, search);

  const save = useMutation({
    mutationFn: () =>
      apiRequest(`/api/awards/${award.id}/slots/${slotKey(slot)}`, {
        method: "PUT",
        body: mode === "judged" ? { team_id: chosen[0] } : { team_ids: chosen, reason: reason.trim() },
      }),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: awardsKey(sessionId) });
      queryClient.invalidateQueries({ queryKey: teamHistoryKey(sessionId) });
      onClose();
    },
  });

  function submit() {
    if (chosen.length === 0) {
      setProblem(t(mode === "judged" ? "awards.winner.pickTeam" : "awards.winner.pickTeams"));
      return;
    }
    if (mode === "override" && reason.trim() === "") {
      setProblem(t("awards.winner.reasonRequired"));
      return;
    }
    setProblem(null);
    if (!save.isPending) save.mutate();
  }

  const heading = t(mode === "judged" ? "awards.winner.chooseHeading" : "awards.winner.overrideHeading", {
    name: award.name,
  });
  return (
    <Modal labelledBy={headingId} onCancel={() => !save.isPending && onClose()}>
      <h2 id={headingId}>{heading}</h2>
      <label className="field" htmlFor={searchId}>
        <span className="field__label">{t("awards.winner.searchLabel")}</span>
      </label>
      <input id={searchId} className="input" value={search} data-autofocus onChange={(e) => setSearch(e.target.value)} />
      <div role={mode === "judged" ? "radiogroup" : "group"} aria-label={t("awards.winner.teamsLabel")} className="list-plain">
        {shown.map((team) => {
          const warning = history.data ? judgedWarning(history.data, team.id, award.id, sessionId) : null;
          const others = history.data ? otherAwards(history.data, team.id, award.id) : [];
          return (
            <label key={team.id} className="list-row">
              <input
                type={mode === "judged" ? "radio" : "checkbox"}
                name="award-team"
                checked={chosen.includes(team.id)}
                onChange={(e) =>
                  setChosen(
                    mode === "judged"
                      ? [team.id]
                      : e.target.checked
                        ? [...chosen, team.id]
                        : chosen.filter((id) => id !== team.id)
                  )
                }
              />{" "}
              <span className="list-row__main">
                {team.number} {team.name}
              </span>
              {warning && (
                <span className="badge badge-warning">
                  {t(warning === "session" ? "awards.winner.warnSession" : "awards.winner.warnSeason")}
                </span>
              )}
              {others.length > 0 && (
                <span className="list-row__meta">
                  {t("awards.winner.otherAwards", {
                    list: others.map((a) => `${a.award_name} (${a.session_label})`).join(", "),
                  })}
                </span>
              )}
            </label>
          );
        })}
      </div>
      {shown.length === 0 && <p className="field__hint">{t("awards.winner.noTeams")}</p>}
      {mode === "override" && (
        <label className="field">
          <span className="field__label">{t("awards.winner.reasonLabel")}</span>
          <textarea className="input" maxLength={500} value={reason} onChange={(e) => setReason(e.target.value)} />
        </label>
      )}
      {(problem || save.isError) && (
        <p className="alert alert-danger" role="alert">
          {problem ?? apiErrorMessage(save.error, t("errors.generic"))}
        </p>
      )}
      <div className="dialog__actions">
        <button type="button" className="btn btn-primary" disabled={save.isPending} onClick={submit}>
          {t("awards.winner.save")}
        </button>
        <button type="button" className="btn" onClick={onClose} disabled={save.isPending}>
          {t("awards.cancel")}
        </button>
```

```tsx
import { Outlet } from "react-router-dom";
import { useQuery, useQueryClient } from "@tanstack/react-query";
import { useTranslation } from "react-i18next";
import { apiRequest, useRealtimeChannel, type RealtimeEvent } from "@tournament-admin/shared";
import type { EventRead, SessionRead } from "../types";

const CHANNEL = "/ws/active-session";

/** The judge's pages always show the event's active session. */
export function JudgeLayout() {
  const { t } = useTranslation();
  const queryClient = useQueryClient();
  const event = useQuery({ queryKey: ["event"], queryFn: () => apiRequest<EventRead>("/api/event") });
  const sessions = useQuery({ queryKey: ["sessions"], queryFn: () => apiRequest<SessionRead[]>("/api/sessions") });
  useRealtimeChannel({
    path: CHANNEL,
    onEvent: (realtimeEvent: RealtimeEvent) => {
      if (realtimeEvent.event === "active_session_changed") {
        queryClient.invalidateQueries({ queryKey: ["event"] });
      }
    },
  });
  if (event.isLoading || sessions.isLoading) return <p>{t("judge.loading")}</p>;
  const session = sessions.data?.find((s) => s.id === event.data?.active_session_id);
  if (!session) return <p>{t("judge.noActiveSession")}</p>;
  return (
    <div>
      <h1>{session.label}</h1>
      <Outlet context={{ session, channelPath: CHANNEL }} />
    </div>
  );
}
```
